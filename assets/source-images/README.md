# Source product images

These are the original images supplied for the Mint Tulsi funnel. Run
`npm run images:optimize` after replacing any source image to regenerate the
PNG and WebP website assets.

`mint2.jpg` is a small source file, so conversion cannot recreate missing
detail. `mint4.webp` contains a visible Freepik watermark and should be replaced
with a licensed, unwatermarked source before a public launch.
